## 📌 Project Overview

**FitTrack** is a comprehensive health and fitness tracker that helps users monitor their daily workouts, nutrition, water intake, and fitness goals with an interactive dashboard.

---

## ✨ Features

- ✅ Dashboard with daily stats (Calories, Steps, Water, Workouts)
- ✅ Log workouts with type, duration, calories, intensity
- ✅ Nutrition tracker (meals, calories, protein, carbs)
- ✅ Water intake tracker with visual bottle animation
- ✅ BMI Calculator with category and health tips
- ✅ Weekly activity chart
- ✅ Goal setting and progress tracking
- ✅ Full workout history with delete option
- ✅ Data saved using localStorage
- ✅ Fully responsive dark theme design
